# GLOWLY 시즌 행사 딜 제안 샘플

가상 스킨케어 브랜드 GLOWLY(8개 SKU)의 오픈마켓 시즌 행사 딜 제안서 샘플입니다. 뷰티 카테고리 Key Account Manager 업무(매출·마진 목표, 딜 구조, 타임딜 운영, 신규 브랜드 육성)를 2쪽에 담았습니다.

- [PDF 보기 (A4 2쪽)](GLOWLY_Beauty_Deal_Proposal_Sample_KR.pdf)

## 구성
1. 상품 역할 분류: 8개 SKU를 슈퍼스타·킬링·육성으로 나누고 판단 근거와 가격 탄력성(가정)을 정리
2. 딜 구조: 역할별 브랜드 할인·플랫폼 쿠폰 분담과 브랜드 설득 포인트
3. 시나리오 비교: 가격·쿠폰 탄력성 기반 예측 (지난 방식 대비 추천안 거래액 +8.0%, 플랫폼 쿠폰비 −73%, 플랫폼 공헌이익 적자 → 흑자), 트레이드오프와 민감도
4. 타임딜 슬롯 배치안과 슬롯당 거래액 기준
5. 실행 일정(D−21 ~ D+7), 경쟁 채널 점검표, 다음 딜로 이어지는 기준
6. 샘플의 근거가 된 실제 경험 (Shopee, 2020–2024)

GLOWLY와 모든 상품·숫자·시간대·수수료율은 가상이며, 특정 회사의 내부 정보나 실제 거래 데이터를 사용하지 않았습니다. 6번 표만 실제 경력입니다.
